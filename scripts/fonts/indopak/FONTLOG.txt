Modifications:
- Instantiate weight axis at 400; retain full glyph repertoire and standard layout.
- Add nine BMP private-use mappings without changing original Unicode mappings.
- Reuse genuine subscript alef, inverted damma and high ain mark glyphs/anchors.
- Compose five spacing pause glyphs from corresponding existing Noto annotation
  glyphs, preserve outline height, assign nonzero advance and GDEF base class.
- Compose high disputed-ayah mark from dedicated Noto U+08E2 glyph; add mark
  attachment data based on existing Noto high-mark anchors.
- Add outline-free U+2003 em space with one-em advance.
- Rename family, PostScript, full, unique, typographic and WWS name records.
- Package real TrueType TTF and WOFF2 without subsetting layout dependencies.

No restricted font assets used. Reference font inspection established symbol
identities only. No Quran data modified or redistributed by this font package.
