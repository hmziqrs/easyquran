## Why we don't "fix" them

The Quran databases are **immutable**:

- **Religious ruling:** the Arabic text of the Qur'an is fixed and must not be
  altered.
- **License:** the Tanzil source is distributed under terms that do not allow
  modifying the content.
- **Source truth:** these four rows are blank in the upstream Tanzil dump
  itself — they are not a build error. The builder packaged them faithfully.

So there is nothing to correct. The only choice is **how to display** an empty
translation verse, and that is a product decision for the translations module.

## Options when implementing translations

For each empty verse, pick one per translation (or globally):

1. **Show Arabic only** (no translation line for that ayah). Probably the
   cleanest — the reader simply has no rendering for that one verse.
2. **Show a neutral placeholder**, e.g. "—" or "(no translation available)".
3. **Serve as-is** (blank). Not recommended — looks like a bug to the reader.

These affect display only. The stored bytes are never changed.
