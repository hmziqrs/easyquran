# Docs — hot plans (implemented, then retired)

This folder holds **active implementation plans only**: briefs meant to be built, shipped, and
then retired. Nothing here is a long-term resource. Permanent contracts, records, and methodology
live in [`documentation/`](../documentation/README.md) — human-owned, untouchable by agents. When
a plan here is fully implemented and verified, the owner distils a permanent record into
`documentation/` by hand and the hot doc is deleted or archived.

Repo-wide hard rules live in [`AGENTS.MD`](../AGENTS.MD).

## Sequencing

Execution order lives in **[`master-plan.md`](master-plan.md)** — the phase-ordered registry
(V → A1 → A2…A19 → P → R, with U alongside). Every plan here except the frozen
[`next-features.md`](next-features.md) carries a "Sequenced by" line near its status pointing at
its phase — next-features.md has none (its phase V is represented in the registry and the frozen
note below); that registry, not this folder listing, is the source of truth for status.

Frozen: [`next-features.md`](next-features.md) takes zero edits until phase V's single correction
pass; [`research/`](research/) is raw evidence — cited, never rewritten.
