# Docs — hot plans (implemented, then retired)

This folder holds **active implementation plans only**: briefs meant to be built, shipped, and
then retired. Nothing here is a long-term resource. Permanent contracts, records, and methodology
live in [`documentation/`](../documentation/README.md) — human-owned, untouchable by agents. When
a plan here is fully implemented and verified, the owner distils a permanent record into
`documentation/` by hand and the hot doc is deleted or archived.

Repo-wide hard rules live in [`AGENTS.MD`](../AGENTS.MD).
